# C#: практикум

Учебные работы по C#: синтаксис, массивы и коллекции, LINQ, ООП, работа с SQL и PostgreSQL.

**Стек:** C# · .NET 8 · LINQ · SQL · PostgreSQL

## Что внутри

**Основы и коллекции**

- `csharp-basics` — базовый синтаксис
- `student-marks` — оценки студента
- `containers` — коллекции
- `namespaces` — пространства имён, сущности и сервисы

**LINQ и данные**

- `book-library-linq` — библиотека книг на LINQ
- `linq-xml` — LINQ to XML
- `student-data-analysis`, `employee-data-analysis` — анализ данных
- `cities-and-populations` — города и население
- `weather-analyzer` — анализ погоды

**ООП и приложения**

- `calculator`, `error-proof-calculator` — калькуляторы
- `fantastic-zoo`, `espionage-operation` — наследование и полиморфизм
- `film-library` — фильмотека
- `books-stack` — книги в стеке
- `inventory-management` — инвентарь в игре
- `product-catalog` — каталог товаров
- `maze` — лабиринт

**SQL и PostgreSQL**

- `postgresql-basics` — основы работы с PostgreSQL
- `postgres-books` — таблицы книг
- `sql-table-relations` — связи между таблицами

## Запуск

Открыть `csharp-lessons.sln` в Visual Studio и запустить нужный проект. Для проектов с PostgreSQL нужна локальная база.
